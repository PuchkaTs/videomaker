## Working rules

- **Don't run full renders unless the user asks.** Edit the source, run `npx tsc --noEmit`, and say which `npm run render:…` command produces the file. The user previews in Studio.
- **Show any script or on-screen copy for approval before generating** (ElevenLabs voices cost credits).
- **Mongolian copy:** avoid loanwords (e.g. «каталог» → «барааны жагсаалт»). Ask for a native check; Claude cannot hear audio, so pronunciation is judged by the user.
- **Keep versions separate** (new composition, new voice folder, new output file) instead of overwriting an approved version.
- **Deliverables:** 1920×1080, 60 fps, H.264 `yuv420p` BT.709, AAC 320k, under 300 MB (20 Mbit/s video ≈ 170 MB for 70 s).

## KublAi agents v2: how it is built

- **Timeline:** `src/kublai-agents-v2/cues.json` is the single source of truth: scene ranges, every event time (`t`), voice clip lists (`voice` for narration, `voiceDialogue`), and the named whooshes (`whooshes`). Animation, audio synthesis and the final mix all read it.
- **Engine:** `time.ts` (seconds-based `useT()`, springs, monotone `track()` keys), `world.tsx` (one CSS-3D world, orbit camera, `Obj` placement with near-plane fade, sub-frame `MotionBlur`), `camera.ts` (one continuous camera path through all sets; blur samples from camera speed + `FLIGHTS`), `backdrop.tsx` (night→day sky, depth-of-field particle sprites, dot wall), `type.tsx` (kinetic titles, captions), `ui.tsx` (chat bubbles, phone, cursor, finger). Scenes live in `scenes/` and are placed at `SET` anchors in `layout.ts`.
- **Audio:** `scripts/kublai-agents-v2-audio.mjs [narration|dialogue]` synthesises the score offline and writes three stems to `public/kublai-v2/stems/<version>/`: `music.wav`, `sfx.wav`, `whooshes.wav` (32-bit float, together -18 LUFS, ducked under that version's voices). Studio shows them as separate tracks (Music, Sound effects, Whooshes). Whooshes and risers are named W01–W22 and R01–R04 in `cues.json`, each with its own `level`; `WHOOSH_LEVEL` trims them all; Studio shows them as markers on "Whooshes (markers)".
- **Voices:** ElevenLabs `eleven_v4`, Mongolian. Agent/narrator: **Uyanga** `2cecqSnkajrth9sJSoEH`. Customer: **Temuulen** `ztVKSTjXnQBPBYroYARn`. Other Mongolian voices: Ganbold `RbMF2tQ1nCK38TfvNGLk` (confident ad male), Naran `sQRZO8j8yYwJ3eCSUFy3`. Chosen takes are in `public/kublai-v2/vo/` and `vo-dialogue/`; alternates sit next to them (`*_take2.mp3`, `*_old.mp3`). Spell for pronunciation in the TTS text only («Эй Ай», «Си Ар Эм», «Кублай»). Gain each clip to about -17.5 LUFS via its `volume` in `cues.json`. The brand ending is `public/kublai/brand-voice-ending.mp3` at 65.0 s.
- **Render:** `npm run render:agents-v2` / `npm run render:agents-v2:dialogue` → `outputs/kublai-agents-v2[-dialogue].mp4` (about 5 min). The script renders video muted, mixes stems + voices with ffmpeg (limiter at -1.4 dBFS) and muxes. **Don't use the Studio Render button for finals**: Remotion's AAC mux leaves audio about 43 ms late.

## Pitfalls already solved (don't reintroduce)

- Render with `--gl=angle` (GPU, about 3× faster) and `--concurrency=4`; concurrency 8 runs Chrome out of memory on this 16 GB Mac.
- No CSS `filter: blur()` on many particles (very slow with motion blur); use the pre-blurred sprites in `sprites.ts`.
- Keep particles behind the UI plane near the frame centre, or they wash out text.
- `opacity < 1` on an `Obj` flattens `preserve-3d`, and CSS 3D depth sorting can draw far objects over near text; hide far objects until needed.
- Module-level JSX fails in the Remotion bundle ("React is not defined"); build JSX lists inside functions.
- Motion blur on readable text during small camera punches makes it ghost; exclude those windows from `FLIGHTS`.
- When verifying audio, check stereo channels; ffmpeg's mono downmix overstates peaks.
- `afftdn` (about 25 ms) and `alimiter` (its attack time) delay audio and ffmpeg does not compensate. For a client's recorded voice, measure sync against the source recording, not the stems, and trim the delay off.
- Each `bundle()` copies `public/` (about 1 GB) into `$TMPDIR` and is not removed unless the script does it; repeated stills runs fill the disk and crash Studio. `empire-r3-stills.mjs` deletes its bundle; the Fitzone stills scripts and `render-video1-review.mjs` do not yet.

## Verifying a render

Probe specs (`ffprobe`), full decode (`ffmpeg -f null`), contact sheets of key frames and dense strips across fast transitions, audio sync against the source mix (cross-correlation), stereo peaks, loudness (`ebur128`). Report what was checked; say plainly that audio was measured, not listened to.
